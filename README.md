# ScopeGuard-k

### Budget-Aware Safety Approval Policies for AI Agent Harnesses

**NTU PE6203 — Generative AI and Agentive AI**  
**Group Project 2 | Nanyang Technological University**

ScopeGuard-k is a budget-aware safety approval framework for AI agents, designed to balance safe task completion with limited human intervention.

Integrated with the AgentDojo benchmark, the framework makes three-way decisions on agent tool calls: **auto-approve, auto-deny, or escalate to a simulated human reviewer**.

The project evaluates the proposed policy against full-approve and full-escalate baselines using Safe Task Completion Rate (TCR@k), Human-in-the-Loop (HITL) Load, API costs, and representative failure cases.
